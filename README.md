## Update the portfolio

- Replace `images/profile.png` to update the photograph without editing HTML.
- Add the final resume as `assets/Marium-Hammad-Resume.pdf`.
- Update dashboard links in the matching file under `projects/`.
- Copy an existing project page when adding a new project, then add its card to `projects/index.html` and optionally `index.html`.
- Keep every claim traceable to a project file, dashboard, course record, or resume.

## GitHub Pages deployment

1. Create a public repository, for example `marium-hammad-portfolio`.
2. Upload all files and folders from this package to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. For a profile-style address, the repository can instead be named `MariumHammad.github.io`.
